# Runtime editorial skills

These workspace-neutral adaptations are embedded in the application bundle, not installed globally. The brief receives Content Strategist; the writer receives both skills; the critic receives Brand Guardian. The factual auditor remains independent.

Source inspiration: [hartmut-ux/ai-marketing-team](https://github.com/hartmut-ux/ai-marketing-team/tree/dc9c8fad68f367a0a66541f0643d81595c4bb775), specifically `skills/content-strategist/shared/SKILL-CORE.md` and `skills/brand-guardian/shared/SKILL-CORE.md`. Pinned source revision: `dc9c8fad68f367a0a66541f0643d81595c4bb775`.

Adaptation removes upstream personal identity, fixed MMIND.ai visuals, DE/EN defaults, mandatory footer, platform-performance claims and provider-specific image instructions. Existing Noosphere schemas, workspace configuration and evidence policy remain authoritative. The MIT notice is retained in LICENSE.upstream.

Local prompt wiring and a successful build establish distribution, not editorial acceptance. Before promotion, evaluate actual model outputs against the rejected generic diagnostic carousel and unrelated offers, then inspect the rendered artifacts. No model-only review certifies visual quality.

Deliverable Designer is an original Noosphere skill embedded for the brief and writer. It adds representation choice, narrative progression and working-aid requirements. It does not copy the withdrawn Kimi skill or an external template library. The decision layout renders a question and exactly two labelled outcomes. This adds a production capability; local fixtures do not prove autonomous editorial acceptance.
