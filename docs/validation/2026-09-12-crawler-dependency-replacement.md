The unsuppressed pip-audit reproduction reports NLTK 3.10.3 / PYSEC-2026-3740 through Crawl4AI. PyPI still advertises NLTK 3.10.3; Crawl4AI 0.9.3 still requires NLTK.

The crawler now uses Playwright directly for rendered pages and BeautifulSoup/markdownify for extraction. This removes Crawl4AI and its NLP/model dependency tree; it does not suppress the advisory or substitute a fabricated package version. The existing discovery/selective/full-crawl jobs, SSE progress, limits, API authentication and per-domain throttling are retained.

The adapter checks robots rules for every document navigation, including redirects, while fetching robots files through the same network safety boundary. Context routing blocks popup initial requests; page CDP interception guards redirects and subresources. Service workers and downloads are disabled. DOM transfer is capped at 2 million characters; conversion runs off the event loop, with bounded link/image inventories. Oversized documents fail explicitly rather than being silently reported as complete.
