## Progression en cours

Le service partagé crée la séquence et lance le sourcing sans demander les cinq identifiants de configuration legacy. Un verrou plan/canal protège la création ; une campagne existante est relue sans changer son état. Une offre indisponible est refusée avant commit.

Les nouvelles campagnes portent `activationMode: manual`, préservé par le résolveur de politique. La composition enregistre les messages et la version de séquence puis s’arrête à `draft/preflight`, avant les inscriptions et actions d’envoi. Le MCP indique `campaign_get_status` pour le suivi.

Régressions : création, rejeu, offre indisponible, campagne active réutilisée intacte, composition manuelle depuis une séquence non publiée sans action d’envoi. L’activation explicite reste à raccorder (ticket 04) ; aucune preuve agent réelle ni nouveau déploiement de cette tranche pour l’instant.

Prochaine tranche : le préflight legacy exige cinq versions, alors que les campagnes mono-canal issues des plans ont offre/ICP/séquence et une politique intégrée. Raccorder un préflight natif adapté, puis l’adaptateur gouverné et un job de programmation transactionnel à l’activation. Le garde `preflight/manual` ne bloque que les brouillons. Conserver le refus d’activation par MCP tant que l’adaptateur n’est pas raccordé.
